# مَجْد | MAJD

ابنِ دولتك، واصنع مستقبلك.

لعبة استراتيجية في عالم ثلاثي الأبعاد: تبدأ قرية صغيرة في موقع تختاره، ثم ترسم الطرق وتبني المساكن ومحطات الماء والكهرباء والمزارع والأسواق، فيزيد السكان وتتطور القرية إلى بلدة ثم مدينة.

## التقنيات

- TypeScript و Vite
- Babylon.js للعالم ثلاثي الأبعاد
- Google Sheets قاعدةً للبيانات، و Google Apps Script خادمًا (مجلد `gas/`)

كل بيانات اللعبة (المباني، التكاليف، الإنتاج، المراحل، الإعدادات) تُقرأ من Google Sheets وتُعدَّل من هناك.

## التشغيل

```bash
npm install
npm run dev      # تشغيل محلي
npm test         # الاختبارات
npm run build    # نسخة الإنتاج في dist/
```

## الخادم

ملفات `gas/` تُلصق في مشروع Apps Script مربوط بملف الشيت:

- `setupDatabase` تنشئ الجداول لأول مرة.
- `addVillageProgression` إضافة تطور القرية على قاعدة بيانات قائمة. تضيف فقط ولا تحذف أو تعدّل أي بيانات.
